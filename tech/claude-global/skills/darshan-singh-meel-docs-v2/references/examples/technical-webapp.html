technical

Tasks app

React + FastAPI + Postgres · on request · browser → tasks table

  • Signs users in with e-mail and password (JWT in an http-only cookie)
  • Lists, adds, changes and deletes tasks per project
  • Shows a dashboard with open and done counts
  • Doesn't send e-mails or reminders
  • Doesn't share projects between users
  • One user per project
  • No offline mode
  1. Any signed-in user can delete another user's task by id Confirmed (test)
  2. Login has no rate limit Confirmed (code)
