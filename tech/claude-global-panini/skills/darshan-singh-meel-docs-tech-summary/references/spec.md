## Sections — fixed, content free
11 sections, these names, this order, every run; missing/extra → refused. Nothing to say → one `line` ("No persisted data: the service is stateless."); core (★) → WARN.

|---|---|---|---|---|

| 2 | Components ★ | `flow`, `components` | runtime parts, real names; one box each (same label) | 8 components, 10 boxes |
| 3 | Main flows ★ | `seq` | flows a new engineer meets first; step table; example where it helps | 4 flows, 7 steps, 6 participants |
| 4 | Data model | `er` | core entities, keys only, cardinality | 12 entities, 5 keys each |
| 5 | Integrations | `integrations` | external systems · direction · protocol · data · auth names | 10 |
| 6 | Tech stack ★ | `stack` | layer · tech · version as pinned · pinning file | 15 |
| 7 | Deploy and environments | `envs` | envs · deploy per env · access; pipeline · rollback · health in bullets | 5 envs |
| 8 | Security and access | – | identity · roles · secret names · personal data · network | 8 bullets / 12 rows |
| 9 | Run locally ★ | `commands` | clone → running, in order, expected output | 8 commands |
| 10 | Top risks ★ | `risks` | design/operational risks + confirmed issues; status per row | 7 |

Also over budget: `bullets` > 8 · `table` > 12 rows · facts > 8 · rules > 5 · `Default(s)` column (config table = Technical depth) · > half the components single files · reading time > 15 min (prose words / 200 + 0.5 min per diagram; code + payloads not counted).

## Fields
```json
{"title": "<repo>: tech summary", "date": "YYYY-MM-DD", "subtitle": "<stack> · <runs on> · <inputs> → <outputs>",
 "commit?": "<short sha>", "graph?": "knowledge graph at <sha> | file scan",  // sha ≠ commit → WARN
 "sections": {"<fixed name>": {"line": "…"} | {"lead?": "…", "blocks?": [ … ], "subsections?": [{"title": "…", "blocks": [ … ]}]}}}
```
Order: `lead` → `blocks` → `subsections`. Subsection titles from the repo (a service, a job); fits-any-repo title ("Overview", "Details") → WARN.

## Blocks
| Type | Fields | Rendered |
|---|---|---|
| `text` | `text` | paragraph |
| `bullets` | `items` | list |
| `table` | `head`, `rows`, `title?` | table |
| `facts` | `rows` [[label, value]] (≤8) | label/value grid |
| `rules` | `rows` [{rule, where: path:line}] (≤5) | list; opt., under At a glance / Main flows |
| `scope` | `does` [1–5], `doesnt` [1–5], `limits?` [≤5] | 3 columns: Does · Doesn't · Limitations |
| `flow` | `title`, `nodes` [{id, label, sub?, kind: actor·service·job·tool·store·external·entry, col, row, tag?}], `edges` [{from, to, label? ≤14 chars, ≤9 between row neighbours, dashed?}], `lanes?` (one per row), `key` | SVG grid; one id per cell; ≥3 boxes |
| `seq` | `title`, `why?`, `participants` [{id, label, kind?}], `steps` [{from, to, do ≤8 words, out, where?, alt?, back?}], `example?` {in, out, source}, `key?` | sequence diagram (numbered) → `# · Step · Output · Where` (`alt` = "If not: …") → IN / OUT |
| `er` | `title`, `entities` [{id, name, keys: ["PK id", "FK x_id", "UK y", "col"], more?: n}], `rels` [{a (one side), b, card: 1:1·1:N·N:1·N:M, on ≤14 chars, logical?}], `key` | cards, rows of 4, cardinality at each end; related = neighbours (row skipped → WARN) |
| `example` | `title`, `in`, `out`, `source` | IN / OUT + source |
| `components` | `rows` [{name, does, tech, where, kind?}] | table; `where` = folder/module (single file only kind job · script) |
| `integrations` | `rows` [{system, direction: in·out·both, via, data, auth?}] | table |
| `stack` | `rows` [{layer, tech, version ("not pinned"), pinned_in}] | table |
| `envs` | `rows` [{env, runs_on, deploy, access}] | table |
| `commands` | `rows` [{cmd, does, expect?}] | table, command as code |
| `risks` | `rows` [{risk, impact, status: Confirmed·Not verified·Design risk·Owner to decide, mitigation, where?}] | table + status chips |
| `pointers` | `rows` [{topic, go, why?}] | table |
Text: `code` + **bold** render; ≤40 words per string (code fields excepted). Participants + boxes → names from Components · Integrations.

## Checks
**ERROR** (no output): fixed section missing/unknown · section without `line` and blocks, or both · required block missing · unknown block · typed row missing a field · risk status · direction · node kind · card outside its list · flow box without id/label/col/row, id or cell twice, <3 boxes, edge to unknown box, lanes < rows · seq <2 participants, step without from/to/do/out or unknown participant · example without in/out/source · ER relation to unknown entity or without `on` · scope `does`/`doesnt` not 1–5 · table head ≠ row length · `TODO` · absolute/machine path (`C:\`, `/c/Users/`, `\\server\share`, `%VAR%\`, `/Workspace/Users/`) · e-mail · phone · rules row without `path:line` · literal secret (`KEY=value`, `token: value`, `user:password@`, `Bearer …`, JWT, `dapi…` · `AKIA…` · `ghp_…` · `xoxb-…` · `sk-…`; write `<redacted>`) · output folder missing.

**WARN**: every budget · one-line core section · generic subsection title · diagram without `key` (seq: fixed key) · edge/relation label > 14 chars · box text cut · step `do` > 8 words · participant ∉ components · integrations · boxes · component ∉ boxes · repo path missing, or `path:line` past file end · link into the graph folder (git-ignored) · `graph` sha ≠ `commit` (behind → recount from code) · chat voice (`you`, `the user`, `Claude`, `as discussed`, `confirm with`, `was skipped`, …) · filler (robust, seamless, leverage, very, simply, comprehensive, …) · string > 40 words · same sentence (≥6 words) twice.
