3 How to find an order and its lines

#StepYou see
1Query orders by order_idone row per status
2Join order_lines on order_id + statusone row per line
INSQL
SELECT o.order_id, o.status, l.line_no, l.sku
FROM export.sales.orders o
JOIN export.sales.order_lines l
  ON l.order_id = o.order_id
 AND l.status = o.status
WHERE o.order_id = 'O-1001';
