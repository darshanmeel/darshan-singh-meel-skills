technical

tabkit

Python library + CLI · on call · CSV/JSON/INI files → records

  • Parses CSV, JSON and INI files into a list of records
  • Checks records against a schema
  • Converts between formats from the command line
  • Loads third-party formats as plugins (entry points)
  • Doesn't stream large files: a file is read whole
  • Doesn't write to databases
  • Files up to the memory of the machine
  • INI sections become records, nested keys are not supported
  1. A plugin error at import stops every command Confirmed (test)
