# Texts: choosing, marking up, analysing, quoting

## Which texts may be printed
| Source | Allowed in material | Source line under the text |
|---|---|---|
| Author dead more than 70 years (UrhG § 64; not legal advice) | whole text or excerpt, from an old print or own transcription - not the notes, afterword or layout of a modern edition | `Joseph von Eichendorff (1788-1857): Mondnacht (1837). Gemeinfrei.` |
| Written for the task | yes - reading texts, dictations, example sentences, Sachtexte with invented but plausible facts | `Für diese Aufgabe verfasst.` |
| The user's own or supplied text | yes; ask where it comes from when it looks published | as the user states |
| Protected work (living author, or dead less than 70 years; translations count by the translator) | no text. Tasks refer to chapter, page, verse of the class edition; short quotations only inside an analysis in the Lösung, with source | `Textgrundlage: <Autor>, <Titel>, S. <n> der Klassenausgabe.` |
| Textbooks, Abitur papers, Vergleichsarbeiten, competition tasks | never, also not reworded task by task | - |

- Check the death year before calling a text gemeinfrei; unsure → write a text for the task.
- Wording of a public-domain text: ask the user to paste the text of the class edition (or to name edition and page) and print that. A text typed from memory is a draft: its source line states the open point as a fact, `Wortlaut noch nicht mit der Klassenausgabe abgeglichen.`, the handover says "not ready" until the user confirms the wording, and task and Erwartungshorizont rest on no single word the user has not confirmed.
- Song settings and anthologies change single words (Eichendorff, Mondnacht V. 4: `nun` in the poem, `nur` in the song text - stated from knowledge, check: class edition). Print one version and name it.
- Spelling of old texts: keep the historical form when the task is literary (say `Schreibung der Vorlage`), modernise for Grundschule reading texts (say `Schreibung angepasst`).
- Sachtexte written for the task carry no real persons' quotes and no invented statistics presented as real: label `Zahlen frei erfunden` or use none.
- Names in example sentences: invented first names, mixed origins; no class names.

## Markup
- Text block: `<div class="quelltext" data-nur-de lang="de">`; title as `<h3>` or `<p><strong>`; source line as `<p class="meta" data-nur-de>` below.
- Poems: one `<p>` per stanza, verses divided by `<br>`, verse number in front of every verse in Grundschule and of every fifth verse otherwise (all verses when the poem is short).
- Prose and Sachtexte: number every fifth line; fix the line breaks with `<br>` so that the numbers hold in print and on screen.
- Tasks stand after the text; a task names its material (`im Gedicht`, `in Z. 5-9`).
- No English under the text. Hard words: glossary entry German → German paraphrase first (`sacht: leise, sanft`), English only as the third column.

Order inside a task set: understand (AFB I) → analyse form and language in their function (AFB II) → interpret, assess, discuss (AFB III).

## Stilmittel: name, proof, effect
Every expected Stilmittel answer has three parts: term · quotation with line · effect in this text. A term without effect earns no point.

| Deutsch | English | Mark |
|---|---|---|
| die Metapher | metaphor | figurative expression without "wie" |
| der Vergleich | simile | with "wie" or "als ob" |
| die Personifikation | personification | thing or idea acts like a person |
| das Symbol | symbol | concrete thing stands for an idea |
| die Alliteration | alliteration | same initial sound in neighbouring words |
| die Anapher | anaphora | same word at the start of verses or sentences |
| der Parallelismus | parallelism | same sentence structure repeated |
| die Antithese | antithesis | opposed terms set against each other |
| die Klimax | climax | rising series |
| die Ellipse | ellipsis | incomplete sentence |
| die Inversion | inversion | changed usual word order |
| die rhetorische Frage | rhetorical question | question that expects no answer |
| die Hyperbel | hyperbole | exaggeration |
| die Ironie | irony | the opposite of what is said is meant |
| das Enjambement | enjambment | sentence runs over the end of the verse |
| die Lautmalerei | onomatopoeia | word imitates a sound |
| der Neologismus | neologism | newly formed word |
| das Wortfeld | word field | words of related meaning |

## Quoting (from Jg. 7; binding in the Oberstufe: Sch4)
- Word for word in quotation marks, with line or verse: `„So sternklar war die Nacht“ (V. 8)`.
- Built into the own sentence; changes in square brackets, omissions `[…]`.
- Indirect reference: `(vgl. Z. 12-15)`.
- Quotation inside a quotation: single marks `‚…‘`.
- A quotation proves, it does not replace the statement: Behauptung → Beleg → Deutung.

## Checks before a text task leaves the desk
- Count verses, stanzas, lines; check every line reference in tasks and solution against the printed text.
- Scan the metre verse by verse yourself; name deviations in the Erwartungshorizont as "möglich", not as required.
- Rhyme scheme with letters; mark impure rhymes.
- Each Stilmittel in the solution: is it really this figure, in this line? Two labels defensible → accept both in the Erwartungshorizont.
- Epoch and dates: author's years, year of the text, epoch borders stated as approximate.
