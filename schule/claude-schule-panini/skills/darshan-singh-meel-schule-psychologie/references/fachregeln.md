# Subject rules: studies, ethics, safety, methods

## Describing research
| Item | Rule |
|---|---|
| Wording | `stützt`, `spricht für`, `legt nahe`, `konnte (nicht) repliziert werden`; never `beweist`, `ist erwiesen` |
| Result | number + base + condition: `36,8 % der Antworten in den kritischen Durchgängen` |
| Correlation | direction and strength only; a causal sentence needs an experiment (manipulated UV, random assignment) |
| Generalisation | name who was studied (age, sex, culture, period) before transferring |
| Theory vs. study | a theory (Freud, Erikson, Maslow) is not "a study"; say what kind of evidence it rests on |
| Paradigm | name the paradigm of each theory; compare by Menschenbild, method, explanation, criticism |
| Currency | say when a classic result has been re-analysed or failed to replicate (`studien.md`) |
| Everyday myths | not taught as fact: "we use 10 % of the brain", fixed "learning types", left/right-brain persons, Rorschach as a valid diagnostic test |

## Methods and statistics (E1.2)
| Term | Must be right |
|---|---|
| Experiment | unabhängige Variable (UV) is manipulated, abhängige Variable (AV) is measured, Störvariablen controlled, random assignment (Randomisierung); Labor-, Feld-, Quasi-Experiment (no random assignment) |
| Versuchsplan | Experimental- and Kontrollgruppe; between-subjects vs. within-subjects (Messwiederholung); Hypothese stated before the data |
| Beobachtung | teilnehmend / nicht teilnehmend, offen / verdeckt, systematisch (categories fixed before) |
| Befragung, Test | standardised; Gütekriterien: Objektivität → Reliabilität → Validität (each needs the one before) |
| Interne / externe Validität | internal: change of the AV is due to the UV; external: result holds outside the study |
| Stichprobe | n, how drawn; repräsentativ only for the population it was drawn from |
| Mittelwert, Median, Streuung | compute and check; mean alone hides spread |
| Korrelation r | −1 to +1; sign = direction; r = 0 no linear relation; says nothing about cause (third variable, reverse direction) |
| Signifikanz | p < 0,05: a result at least this large would be unlikely if there were no effect; not "95 % sure the hypothesis is true"; not the size of the effect |
| Level limit | E and GK compute Häufigkeit, Prozent, Mittelwert, Median, Spannweite; r and p are given and read; no test computation (Chi-Quadrat, t-Test): `kcbg.md` level guide |
| Längsschnitt / Querschnitt | same persons over time vs. different age groups at one time (cohort effect) |

Invented data: label `Modelldaten (erfunden)` / `model data (invented)`; small n, numbers that compute cleanly; never mixed with real study data in one table.

## Research ethics (L3) - checklist for every study task
| Principle | Question for the task |
|---|---|
| Informierte Einwilligung (informed consent) | did participants know what would happen; could children consent? |
| Freiwilligkeit, Recht auf Abbruch | could they stop without disadvantage? |
| Schutz vor Schaden | physical or mental strain; lasting effects? |
| Täuschung | was deception needed; was it resolved afterwards? |
| Aufklärung danach (Debriefing) | were participants informed and looked after afterwards? |
| Vertraulichkeit, Anonymität | are data anonymous? |
| Abwägung | does the gain in knowledge justify the strain; would an ethics committee approve it today? |

- Codes to name: Berufsethische Richtlinien of DGPs and BDP; APA Ethical Principles; Deklaration von Helsinki (medical research). check: dgps.de for the current version before quoting wording.
- Animal studies (Pavlov, Skinner): name the animal-welfare question; no fuller judgement needed.

## Safety in class
| Area | Rule |
|---|---|
| Cases | invented persons, age and setting plausible, marked `Fallbeispiel (erfunden)`; no resemblance to class members; no real public persons diagnosed |
| Self-tests | only to show a method; anonymous, voluntary, no collection of results, no interpretation of single persons; real diagnostic tests (IQ, NEO-FFI, clinical questionnaires) are described, not administered - they are also copyrighted |
| Personal questions | tasks never require own disorders, family conflicts, traumas, sexuality, religion; offer a neutral alternative (`oder wählen Sie das Fallbeispiel`) |
| Classroom experiments | harmless only: Gedächtnisspanne, Stroop, optical illusions, reaction time, chunking; state aim, allow opting out, anonymous tally, debrief; no deception that embarrasses, no stress induction, no re-enactment of Milgram, Asch with real pressure, or prison role plays |
| Clinical topics (Q4.2, Q4.3, Q1.4) | describe by criteria; person-first language (`Menschen mit Depression`, not `Depressive`); no stigma words; disorders are not explained by "weakness"; no instructions or method details for self-harm, eating restriction, substance use |
| Suicide, self-harm | only when the curriculum topic needs it; no methods, no romanticising; name help: Vertrauenslehrkraft, Schulpsychologie, ärztliche / psychotherapeutische Sprechstunde, Telefonseelsorge (check: telefonseelsorge.de for current contact data before printing) |
| Therapy | material informs, it does not advise; no treatment recommendation for a person; Psychotherapie vs. Beratung kept apart |
| Classification | ICD-10 chapter V (F codes) is what the KC names; ICD-11 exists (WHO, in force internationally since 2022) - check: bfarm.de for use in Germany; DSM-5 (KC: "DSM-V") |
| Stereotypes | no trait or disorder tied to gender, origin, religion, class; group research reported as distributions, not as "the X are ..." |

Test before finishing: could a student in the room feel described, diagnosed or pushed to disclose? → rewrite.

## Material types
| Material | Rule for writing | Task pattern (operator, AFB) |
|---|---|---|
| Fallbeispiel | invented, 80-300 words, behaviour described without the technical term the task asks for | beschreiben (I) → erklären / analysieren with a theory (II) → beurteilen the explanation, compare a second theory (III) |
| Studienzusammenfassung | pattern of `studien.md`; `nach: <authors year>` | wiedergeben (I) → UV, AV, Hypothese bestimmen; erklären (II) → beurteilen (Gütekriterien, ethics, transfer) (III) |
| Modell, Schaubild | own drawing; components labelled; `modelle-animationen.md` | beschreiben / darstellen (I) → erläutern at a case (II) → überprüfen limits (III) |
| Daten | small table or chart, labelled invented or with source | beschreiben (I) → auswerten, berechnen (II) → interpretieren with caution, name alternative explanations (III) |
| Theorietext | written for the task, 120-300 words, in the vocabulary of one paradigm | zusammenfassen (I) → vergleichen with a second paradigm (II) → Stellung nehmen (III) |

## Case analysis (fixed steps)
1. Beschreiben: observable behaviour and reported experience, kept apart (L1).
2. Zuordnen: terms of the chosen theory matched to parts of the case.
3. Erklären: how the theory accounts for the behaviour (chain, not labels).
4. Alternative: one second theory or paradigm, shorter.
5. Beurteilen: what each explanation covers and leaves out; what one could do (intervention), tied to the theory.

Marking: points for correct matching and the explanatory chain, not for the theory chosen when the task leaves the choice.
- A model answer may use only what the material and the course gave; content beyond it is marked `falls im Kurs behandelt`.

## Typical mistakes of students (use in "Typischer Fehler")
| Topic | Mistake | Right |
|---|---|---|
| Conditioning | negative Verstärkung = Bestrafung | negative reinforcement removes something unpleasant → behaviour increases; punishment → behaviour decreases |
| Conditioning | the conditioned stimulus is called "the reward" | classical: stimuli are paired before the reaction; operant: the consequence follows the behaviour |
| Conditioning | NS, UCS, CS, UCR, CR mixed up | the bell is NS before, CS after; the reaction to the bell alone is the CR |
| Memory | Kurzzeitgedächtnis = "what I learned yesterday" | seconds, not days; yesterday's content is in long-term memory |
| Memory | Ultrakurzzeitgedächtnis and Kurzzeitgedächtnis merged | sensory register: under 1 s (visual), large capacity, before attention |
| Memory | forgetting = deleted | often retrieval failure or interference; cue can bring it back |
| Methods | correlation read as cause | third variable, reverse direction |
| Methods | "signifikant" = large or important | unlikely under chance; says nothing about size |
| Methods | UV and AV swapped | UV is what the researcher changes; AV is what is measured |
| Freud | Unterbewusstsein | Freud's terms: das Unbewusste, das Vorbewusste, das Bewusste |
| Freud | Es, Ich, Über-Ich as places in the brain | functional instances of a model |
| Piaget | ages as fixed limits | approximate; order is the claim, ages vary |
| Social | Milgram "shows people are cruel" | shows the power of the situation and of authority; 35 % stopped before the end |
| Social | Asch: "75 % conformed" | 75 % at least once; about 37 % of critical answers |
| Clinical | diagnosis from one symptom | criteria, duration, impairment; diagnosis is for professionals |
| Traits | Big Five as types | dimensions with continuous values |
