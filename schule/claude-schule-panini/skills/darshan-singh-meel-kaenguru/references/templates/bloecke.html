Regeln / Rules

Bei jeder Aufgabe ist genau eine der fünf Antworten (A) bis (E) richtig. Trage den Buchstaben in den Antwortzettel auf der letzten Seite ein.

For each problem exactly one of the five answers (A) to (E) is correct. Enter the letter in the answer sheet on the last page.

Für eine richtige Antwort gibt es die Punkte der Aufgabe. Für eine falsche Antwort wird ein Viertel der Punkte abgezogen. Ohne Antwort gibt es 0 Punkte.

For a correct answer you get the points of the problem. For a wrong answer a quarter of the points is deducted. Without an answer you get 0 points.
