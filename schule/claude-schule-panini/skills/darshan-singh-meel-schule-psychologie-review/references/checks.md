# Subject checks Y1-Y10 (in addition to the base checklist 1-12)

Each check: what to look at · Must when. Evidence for every finding: file, task id or line, quoted text.

| # | Check | Look at | Must when |
|---|---|---|---|
| Y1 | Curriculum | source line names the KCBG (Fachrichtung Gesundheit und Soziales, Schwerpunkt Erziehungswissenschaft) or `Orientierung: KCBG Psychologie` for a school-own course; competence code exists (K1.1-K1.14, K2.1-K2.11, K3.1-K3.9, K4.1-K4.9, K5.1-K5.12) and its AFB matches the code's block; wording as in `kcbg.md`; Leitidee L1-L4; Themenfeld number and title match the Kurshalbjahr; no "KCGO Psychologie", no Leistungskurs; content within the Themenfeld and the level guide of `kcbg.md` | invented code or wording; wrong Themenfeld; a curriculum cited that does not exist |
| Y2 | Study facts | each study: authors, year, n and who, design (UV, AV, conditions, control), result with number and base, as in `studien.md`; `nach: <authors year>` under the summary | any fact differs from the reference row or the primary publication; result without base so that a task has two answers |
| Y3 | Evidence wording | `stützt / spricht für`, not `beweist`; correlation not read as cause; generalisation limited to the sample; theory not called a study; myths (10 % brain, learning types) not taught as fact | causal claim from correlational data; `beweist`; a myth as fact |
| Y4 | Models and figures | components, order, arrows, labels, capacity and duration figures as in `modelle-animationen.md`; one set of abbreviations (UCS/UCR/CS/CR); 2 × 2 of reinforcement and punishment; model limit named | wrong order, arrow, term; figure, text, solution and animation differ |

| Y7 | Safety | cases invented and marked; no diagnosis of self, classmates, relatives, public persons; no required disclosure; self-tests anonymous, voluntary, not collected; classroom experiments harmless with opt-out and debriefing; clinical topics: criteria, person-first language, no stigma, no method details, help route named | any breach |
| Y8 | Statistics | n stated; mean, median, percentages recomputed; r in −1 ... +1 with correct reading; significance explained correctly; invented data labelled `Modelldaten (erfunden)`; not mixed with real data | wrong computation; wrong explanation of r or p; invented data shown as real; task above the level limit of `kcbg.md` (significance test, Standardabweichung, r or p computed) |

| Y10 | Subject terms DE/EN | terms as in `begriffe.md`; no false friends (psychisch ≠ psychic, Bewertung → appraisal, Reiz → stimulus, Wiederholen → rehearsal, das Unbewusste → the unconscious); `Reaktion` → response in conditioning | wrong term changes the meaning |

## Recompute list
- Percentages: `part / base`; base named (answers vs. persons; critical trials vs. all trials).
- Asch: 12 critical of 18 trials; 36.8 % = answers, about 75 % = persons who conformed at least once; Milgram: 26 of 40 = 65 %, 14 of 40 = 35 % stopped earlier.
- Memory span data: mean and median per condition; chunking example - count units, not letters.
- Ebbinghaus: values fall monotonically; axis says Ersparnis.
- 2 × 2 tables: each cell against the definition.
- Test: parts add up to the total; AFB shares; grade key thresholds.

## Wording of typical findings
- `Studienfakt` - quote the statement; give the reference row; fix: corrected sentence with `nach: <authors year>`.
- `Beleg` - quote the over-claim; fix: `stützt` wording or the missing limit.
- `Modell` - name the wrong element (store, arrow, label); give the corrected picture in words.
- `Sicherheit` - quote the task; name the risk (disclosure, diagnosis, pressure); fix: invented case or neutral alternative.
- `Ethik` - name the missing principle; fix: the added sub-task.
- Bilingual findings: kinds and format as in base `references/review.md`.
