| Berechne die Geschwindigkeit in m/s. | Calculate the speed in m/s. |

| Die Reibung wird vernachlässigt. | Friction is neglected. |
| Der Körper wird um 4,0 cm ausgelenkt und losgelassen. | The body is displaced by 4.0 cm and released. |
| Gegeben / Gesucht / Rechnung / Antwort | Given / To find / Calculation / Answer |
| Zeichne das t-s-Diagramm. | Draw the t-s diagram. |
| Baue den Versuch nach der Skizze auf. | Set up the experiment according to the sketch. |
