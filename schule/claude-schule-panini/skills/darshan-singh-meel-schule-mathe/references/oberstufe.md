## Digital tools (KCGO 2.5; Abiturerlass 2027, 23.4)
- Two calculator technologies in the Landesabitur 2027: **WTR** (wissenschaftlich-technischer Taschenrechner, neither graphing nor CAS) or **CAS** (Taschencomputer or app, also called MMS). The school fixes one per exam group at the start of the Qualifikationsphase. A graphing calculator without CAS (GTR) is not named in the 2027 Erlass: check: Abiturerlass of the exam year if the school still uses one.
- Every candidate must be able to use the calculator for: Wertetabelle of a term, single and cumulated values of the Binomialverteilung, values of the Normalverteilung with μ and σ.
- WTR in addition (Erlass 2027): Polynomgleichungen bis dritten Grades, näherungsweises Lösen von Gleichungen, eindeutig lösbare LGS bis drei Unbekannte, Ableitung an einer Stelle, bestimmtes Integral, Mittelwert und empirische Standardabweichung, Umkehrfunktion der Normalverteilung.
- CAS: Polynomgleichungen, LGS, Ableitung, Stammfunktion und bestimmtes Integral, Matrizen (Produkt, Inverse), Mittelwert und Standardabweichung, Umkehrfunktion der Normalverteilung.
- Calculator-specific notation is not allowed in solutions (`binomcdf(100,0.5,60)` → `P(X ≤ 60) = F(100; 0,5; 60)`).

## Operators and the calculator ("Hinweise", part II)
| Operator | Documentation expected |
|---|---|
| berechnen | a calculation by hand: steps that do not rest on the extended calculator functions, graphing or CAS. Not used for values nobody computes by hand (cumulated binomial, normal distribution) |
| bestimmen / ermitteln | any function of WTR or CAS may be used; the use is documented (equation set up, then "ermittelt mit dem WTR", result) |
| rechnerisch bestimmen | a calculation is required; a graphical solution from the material is excluded |
| grafisch bestimmen | a graphical solution is required; a calculation is excluded |

## Notation used in Landesabitur tasks ("Hinweise", part I) - use it in Oberstufe material
- `Gegeben ist die in ℝ definierte Funktion f mit f(x) = ...` · graph of f: `G_f` (introduce it once).
- Intervals: `[a; b]`, `]a; b[`, `[a; b[`. Limits: `lim` with `x → +∞`.
- Coordinates in space `x, y, z` or `x₁, x₂, x₃` - one system per paper.
- Binomial: `P(X = k)`, `B(n; p; k)`; cumulated `P(X ≤ k) = F(n; p; k)`; `P(X ≥ k) = 1 − F(n; p; k − 1)`. Events: `A ∩ B`, `A ∪ B`, `A \ B`, complement with overline.

## Typical mistakes (for Erwartungshorizont notes and distractors)
| Topic | Mistake |
|---|---|
| Ableiten | chain rule inner derivative left out: `(e^(2x))' = e^(2x)`; product rule as product of derivatives |
| Extremstellen | `f'(x) = 0` taken as sufficient; y-value missing for the point; boundary values ignored on an interval |
| Integral | area = integral across a zero (orientierter Flächeninhalt); `+ c` logic mixed into definite integrals; limits swapped |
| Integral im Sachkontext | Bestand = Integral without the Anfangsbestand; unit of rate × time not checked |
| Exponentialfunktionen | `ln(a + b) = ln a + ln b`; growth factor and growth rate mixed (1,05 vs. 5 %) |
| Vektoren | Punkt and Vektor mixed; direction vector normalised without need; parameter of two lines named the same |
| Lagebeziehungen | parallel concluded from one proportional coordinate; identical vs. parallel not separated by Punktprobe |
| Skalarprodukt | angle between lines > 90° given; absolute value forgotten |
| Stochastik | `P(X ≥ k)` computed as `1 − F(k)`; bedingte Wahrscheinlichkeit P(A∣B) confused with P(B∣A); Bernoulli model used although p changes |
| Hypothesentest | hypotheses about the sample instead of p; significance level read as probability that H₀ is true |
