# NWT modules and their curriculum anchors

Modules are proposals for a school's Wahlunterricht curriculum (no state list exists). The anchor columns use Inhaltsfeld names as printed in the KC Sekundarstufe I - Gymnasium of the subject (read; `sources.md`). Physik anchors include the Schwerpunkt and stage from the physics skill's `sek1.md`. For Chemie and Biologie only the Inhaltsfeld names were read: Schwerpunkte and standards → check: KC of the subject, or the Chemie/Biologie subject skill when installed.

## Using the table
- One carrying subject per module; its KC supplies Kompetenzbereich, standard and Inhaltsfeld for the lesson plan (`hessen-nwt.md`, citing rows). Links are named in the plan under Lernvoraussetzungen, not cited as a second KC reference.
- Check with the user that the anchor content has been taught in the compulsory subject by that year; otherwise the first lesson of the module teaches it (plan it).
- Chemie and Biologie modules (10-12): chemicals and organisms need the safety rules of those subjects → check: RiSU I - 3 (Gefahrstoffe), I - 6 (Biostoffe), I - 7 (Lebewesen); household substances only unless the teacher confirms the Gefährdungsbeurteilung.
- A module of 8-12 double lessons: problem and requirements (1) · basics with experiments (2-3) · design (1-2) · build (2-3) · test and optimise (1-2) · presentation and assessment (1).
- Every module has one calculation core (the column "Core quantities") - this is where units, digits and plausibility are checked.
