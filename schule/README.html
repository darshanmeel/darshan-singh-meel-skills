repo ddb0059+dirty

Markdown skills + check script · on request · topic and level → HTML material

Teachers get print-ready lessons, worksheets with solutions and tests for Hessen schools and German courses, each solved and checked by a reviewer skill.

Material follows the Hessen curriculum and exam formats, and every German line has the closest natural English sentence under it.

  • Writes lesson plans, worksheets with solutions, tests with marking schemes, explanations and animations
  • Covers Grundschule and Gymnasium subjects, DaF A1–C1, Mathe-Känguru and Einstellungstest practice
  • Pairs each subject skill with a reviewer that solves every task
  • Checks the HTML with a standard-library script
  • Doesn't copy textbook or exam tasks: it writes originals in the same style
  • Doesn't use real student data
  • Doesn't cover other federal states' curricula
  • Curriculum facts are only as current as the official pages named in sources.md
  1. No open Must or Should issue (not reviewed): 1 other item under Known issues

1 What it is and why

  • What: 27 Claude Code skills for teaching material: a shared base, subject skills and their reviewers.
  • Why: Material that matches the Hessen framework, the level and the exam format, without checking each rule by hand.
  • Key idea: The base skill holds the framework, templates and review rubric; each subject skill adds only its subject.
  • Result: Self-contained HTML in A4 print layout, with English lines that can be switched off.

5 Value and cost

  • Value: Curriculum-fit material and an independent check of every task.
  • Cost: Python 3 for the check script; standard library only.

6 Design and operational risks

  • A curriculum change on the official pages needs an update of sources.md and the affected skill.
  • A change in the full version and not its sūtra twin fails check_repo.

7 Words used

  • KC / KCGO — Hessen Kerncurriculum for Sek I and for the Oberstufe
  • AFB — Anforderungsbereich: the level of thinking a task asks for
  • DaF / DaZ — German as a foreign or second language
  • Erwartungshorizont — the expected answers and points of a test
