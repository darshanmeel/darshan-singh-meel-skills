## False friends and traps
| German | Not | But |
|---|---|---|
| die Karte | card | map |
| der Maßstab | measure | scale |
| die Legende | legend (story) | key; "legend" is accepted on maps |
| das Klimadiagramm | climate chart | climate graph / climate diagram |
| der Raum | room | area, region, space (by context) |
| die Bevölkerung | population of animals | population (people); `Einwohner` = inhabitants |
| die Billion | billion | trillion; `Milliarde` = billion |
| aktuell | actual | current |
| die Industrie | industry (all sectors) | manufacturing industry; English "industry" is wider |
| die Konjunktur | conjuncture | economic cycle |

## Wording to avoid → use
| Avoid | Use |
|---|---|
| Dritte Welt, unterentwickelt, rückständig | Länder des Globalen Südens; wenig entwickelter Staat (KCGO wording); name indicator and year |
| Eingeborene, Stamm (as a general label) | Bevölkerung, indigene Bevölkerung, name of the group |
| Naturkatastrophe (for the event alone) | Naturereignis; Katastrophe only with the damage to people |
| "Die Natur zwingt ..." | "Die Bedingungen begrenzen/ermöglichen ..." |
| Flüchtlingswelle, -strom | Fluchtbewegung, Zahl der Geflüchteten with year and source |
