Brüche mit verschiedenen Nennern addierenAdding fractions with different denominators

Aufgabe 1 / Task 1

Ergebnis: a) 34   b) 56   c) 710

Result: a) 34   b) 56   c) 710

Lösungsweg: Nur der Bruch mit dem kleineren Nenner wird erweitert.

Solution steps: Only the fraction with the smaller denominator is expanded.

a) 14 + 12 = 14 + 24 = 34   b) 23 + 16 = 46 + 16 = 56   c) 310 + 25 = 310 + 410 = 710

Typischer Fehler: Zähler und Nenner werden einzeln addiert: 14 + 12 = 26. Das Ergebnis 26 = 13 ist kleiner als 12 und kann deshalb nicht stimmen.

Typical mistake: Numerators and denominators are added separately: 14 + 12 = 26. The result 26 = 13 is smaller than 12 and therefore cannot be right.

Aufgabe 2 / Task 2

Ergebnis: a) 712   b) 1712   c) 56

Result: a) 712   b) 1712   c) 56

Lösungsweg: Der kleinste gemeinsame Nenner ist das kgV der beiden Nenner: 12, 12 und 30.

Solution steps: The least common denominator is the lcm of the two denominators: 12, 12 and 30.

a) 13 + 14 = 412 + 312 = 712

b) 34 + 56 = 912 + 1012 = 1912 = 1712

c) 710 + 215 = 2130 + 430 = 2530 = 56

Mit dem Nenner 24 ist der Weg bei b) länger, aber auch richtig: 1824 + 2024 = 3824 = 1712.

With the denominator 24, the path in b) is longer but also correct: 1824 + 2024 = 3824 = 1712.

Typischer Fehler: Das Ergebnis wird nicht gekürzt: 2530 statt 56.

Typical mistake: The result is not simplified: 2530 instead of 56.

Aufgabe 3 / Task 3

Ergebnis: Die Schorle passt nicht in die Flasche: 34 Liter + 25 Liter = 1320 Liter, das ist mehr als 1 Liter.

Result: The spritzer does not fit into the bottle: 34 litre + 25 litre = 1320 litres, that is more than 1 litre.

Lösungsweg / Solution steps: 34 + 25 = 1520 + 820 = 2320 = 1320

Das sind 320 Liter zu viel.

That is 320 litre too much.

Typischer Fehler: Die Rechnung steht da, aber der Vergleich mit 1 Liter und der Antwortsatz fehlen.

Typical mistake: The calculation is there, but the comparison with 1 litre and the answer sentence are missing.

Aufgabe 4 / Task 4

Ergebnis: Es gibt zwei Möglichkeiten: 14 + 46 und 34 + 16.

Result: There are two possibilities: 14 + 46 and 34 + 16.

Lösungsweg: Beide Brüche werden auf den Nenner 12 erweitert: a4 = 3·a12 und b6 = 2·b12. Für die Zähler gilt dann 3 · a + 2 · b = 11.

Solution steps: Both fractions are expanded to the denominator 12: a4 = 3·a12 and b6 = 2·b12. For the numerators, 3 · a + 2 · b = 11 then holds.

Probiere a = 1, 2, 3: a = 1 ergibt b = 4. a = 2 ergibt 2 · b = 5, das geht nicht. a = 3 ergibt b = 1. Ab a = 4 ist 3 · a schon größer als 11.

Try a = 1, 2, 3: a = 1 gives b = 4. a = 2 gives 2 · b = 5, that does not work. a = 3 gives b = 1. From a = 4 on, 3 · a is already greater than 11.

Probe / Check: 14 + 46 = 312 + 812 = 1112   34 + 16 = 912 + 212 = 1112

Wer nur gekürzte Brüche zulässt, erhält eine Lösung: 34 + 16.

Whoever allows only simplified fractions gets one solution: 34 + 16.

Typischer Fehler: Nach der ersten gefundenen Lösung wird aufgehört.

Typical mistake: The work is stopped after the first solution found.
