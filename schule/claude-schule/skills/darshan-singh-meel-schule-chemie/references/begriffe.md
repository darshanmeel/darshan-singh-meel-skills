Use for the glossary of every output (5-10 terms per lesson) and for the English lines. German nouns with article. English = the term of English-language school chemistry (British spelling: `sulfur` is IUPAC and stays; `colour`, `neutralisation`, `oxidising`; American only if the user asks). Own list, not an official one; a term missing here: standard English school curriculum term (base `bilingual.md`).

## False friends and traps
| German | Not | But |
|---|---|---|
| die Lauge | lye (old-fashioned) | alkaline solution / alkali |
| der Stoff | stuff, material | substance |
| die Verbindung | connection | compound |
| die Lösung | solution = both "Lösung einer Aufgabe" and "Lösung eines Stoffes": keep clear from context | solution (chemistry) / answer, solution (task) |
| edel / unedel | precious / base metal in everyday use | in the redox series: less reactive / more reactive metal; "noble" only for the noble metals |
| die Spannung | tension | voltage |
| das Edukt | educt (rare in English) | reactant |
| die Probe | probe | sample (Stoffprobe) / test (Nachweis: "Fehling's test") |
| das Reagenzglas | reagent glass | test tube |
| die Base / basisch | basic (also "simple") | base / alkaline or basic - "basic" only where no confusion arises |
| brennbar / entzündbar | inflammable (ambiguous) | flammable |
| Kohlenstoffdioxid | carbon dioxyde, carbonic acid | carbon dioxide |
